Two changes to WorkspacePage.tsx:

**Change 1 — Fetch opportunity title via secondary useQuery:**

After the existing `workspaceQuery` and `sectionsQuery`, add a third query that fetches the opportunity title from the public opportunity API. The public endpoint `GET /api/v1/opportunities/:id` requires no auth for published opportunities:

```typescript
// Secondary fetch for opportunity title (public endpoint — no auth needed for published opps)
const opportunityQuery = useQuery({
  queryKey: ['opportunity-title', workspace?.opportunity_id],
  queryFn: async () => {
    const res = await fetch(`/api/v1/opportunities/${workspace!.opportunity_id}`);
    if (!res.ok) return null;
    const data = await res.json() as { title?: string };
    return data.title ?? null;
  },
  enabled: !!workspace?.opportunity_id,
  staleTime: 5 * 60_000, // opportunity title rarely changes
});
```

Note: `workspace` is derived AFTER the loading/error checks, so place this query BEFORE the loading checks but using `workspaceQuery.data?.opportunity_id` as the dependency:

```typescript
const opportunityQuery = useQuery({
  queryKey: ['opportunity-title', workspaceQuery.data?.opportunity_id],
  queryFn: async () => {
    const oppId = workspaceQuery.data!.opportunity_id;
    const res = await fetch(`/api/v1/opportunities/${oppId}`);
    if (!res.ok) return null;
    const data = await res.json() as { title?: string };
    return data.title ?? null;
  },
  enabled: !!workspaceQuery.data?.opportunity_id,
  staleTime: 5 * 60_000,
});
```

Place this query right after the `sectionsQuery` declaration and before the `useWorkspaceStore` line.

**Change 2 — Render title instead of UUID:**

Replace line 98 which currently reads:
```tsx
<p className="usa-hint">Opportunity: {workspace.opportunity_id}</p>
```

With:
```tsx
<p className="usa-hint">
  Opportunity: {opportunityQuery.data ?? workspace.opportunity_id}
</p>
```

This renders the title when loaded, falling back gracefully to the UUID if the fetch fails.

**Change 3 — Add overflow:hidden to grid-col-6 content div:**

Find the content column div (currently line 123):
```tsx

```

Change it to:
```tsx
<div className="grid-col-6" data-testid="workspace-section-content" style={{ overflow: 'hidden' }}>
```

This prevents BudgetBuilder and AttachmentManager tables from visually overflowing into the grid-col-3 Readiness Dashboard column.
