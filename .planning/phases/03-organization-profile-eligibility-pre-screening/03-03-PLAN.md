This is the core evaluation engine. It evaluates submitted responses against the opportunity's eligibility_rules and produces an EligibilityResult.

```typescript
import { pool } from '../../db/client';

export interface SubmittedResponse {
  question_id: string;
  selected_option_id?: string;
  response_text?: string;
}

export interface EligibilityResult {
  overall_result: 'eligible' | 'likely_eligible' | 'needs_attention' | 'ineligible';
  triggered_rules: Array<{
    rule_id: string;
    severity: 'hard_blocker' | 'advisory';
    explanation_text: string;
    opportunity_section_link?: string;
  }>;
  next_step: string;
  workspace_access_granted: boolean;
}
```

Implement `class PrescreeningEvaluationService`:

**`async evaluateResponses(opportunityId: string, orgId: string, responses: SubmittedResponse[]): Promise<EligibilityResult>`**

Algorithm:
1. Check if already submitted (SELECT 1 FROM eligibility_responses WHERE opportunity_id=$1 AND org_id=$2 LIMIT 1). If exists, throw 409 AppError with code ALREADY_SUBMITTED.

2. Load eligibility_rules for this opportunity:
   ```sql
   SELECT rule_id, criterion_field, operator, criterion_value, severity, explanation_text
   FROM eligibility_rules
   WHERE opportunity_id = $1
   ORDER BY display_order
   ```

3. Load prescreening_questions with their options and rule links:
   ```sql
   SELECT q.question_id, q.question_text, q.question_type,
          q.conditional_on_question_id, q.conditional_on_option_id,
          q.display_order,
          json_agg(
            json_build_object(
              'option_id', o.option_id,
              'option_text', o.option_text,
              'triggers_rule_id', o.triggers_rule_id
            ) ORDER BY o.display_order
          ) FILTER (WHERE o.option_id IS NOT NULL) AS options
   FROM prescreening_questions q
   JOIN prescreening_questionnaires pq ON pq.questionnaire_id = q.questionnaire_id
   LEFT JOIN prescreening_options o ON o.question_id = q.question_id
   WHERE pq.opportunity_id = $1
   GROUP BY q.question_id, q.question_text, q.question_type,
            q.conditional_on_question_id, q.conditional_on_option_id, q.display_order
   ORDER BY q.display_order
   ```

4. Build response map: `Map<questionId, SubmittedResponse>` from the `responses` array.

5. Evaluate each submitted response against triggered rules:
   - For each response, find the corresponding question
   - Find the selected option (if selected_option_id provided) and check `options.triggers_rule_id`
   - If triggers_rule_id is not null, find the matching rule in eligibility_rules
   - Add to triggered_rules array: `{ rule_id, severity, explanation_text }`

6. Determine overall_result:
   - If ANY triggered rule has severity='hard_blocker' → `ineligible`
   - Else if 3+ triggered rules have severity='advisory' → `needs_attention`
   - Else if 1-2 triggered rules have severity='advisory' → `likely_eligible`
   - Else (no triggered rules) → `eligible`

7. Determine next_step string based on overall_result:
   - `eligible`: "You may proceed to create an application workspace."
   - `likely_eligible`: "You appear eligible but should review the advisory notes before proceeding."
   - `needs_attention`: "Please review the items below with your team before proceeding."
   - `ineligible`: "Based on your responses, your organization does not meet the eligibility requirements for this opportunity."

8. `workspace_access_granted = overall_result !== 'ineligible'`

9. Compute rule_evaluation_result per response:
   - If the response triggered a hard_blocker rule → 'violated'
   - If the response triggered an advisory rule → 'advisory'
   - If the response did not trigger any rule → 'met'
   - If question was conditional and not shown → 'not_applicable'

10. INSERT all responses into eligibility_responses:
    ```sql
    INSERT INTO eligibility_responses
      (opportunity_id, org_id, question_id, selected_option_id, response_text,
       rule_evaluation_result, overall_result)
    VALUES ($1, $2, $3, $4, $5, $6, $7)
    ON CONFLICT (opportunity_id, org_id, question_id) DO NOTHING
    ```
    Use a transaction: BEGIN → insert all rows → COMMIT (rollback on error).

11. Return the EligibilityResult.

Export: `export const prescreeningEvaluationService = new PrescreeningEvaluationService();`

**Step A: Create `client/src/api/prescreeningApi.ts`**

```typescript
import apiClient from './apiClient';
import type { EligibilityResult } from './organizationsApi';

export interface PrescreeningQuestion {
  question_id: string;
  question_text: string;
  question_type: 'single_choice' | 'multiple_choice' | 'text' | 'boolean';
  options: Array<{
    option_id: string;
    option_text: string;
    triggers_rule_id?: string;
  }>;
  conditional_on_question_id?: string;
  conditional_on_option_id?: string;
  display_order: number;
}

export interface PrescreeningQuestionnaire {
  questionnaire_id: string;
  questions: PrescreeningQuestion[];
}

export interface SubmitResponseInput {
  question_id: string;
  selected_option_id?: string;
  response_text?: string;
}

export const prescreeningApi = {
  async getQuestionnaire(opportunityId: string): Promise<PrescreeningQuestionnaire> {
    const { data } = await apiClient.get(`/opportunities/${opportunityId}/prescreening`);
    return data;
  },
  async submitResponses(opportunityId: string, responses: SubmitResponseInput[]): Promise<EligibilityResult> {
    const { data } = await apiClient.post(
      `/opportunities/${opportunityId}/prescreening/submit`,
      { responses }
    );
    return data;
  },
};
```
