   ```ts
   const UUID_REGEX = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;
   ```

2. In `handleAssignSubmit`, after the empty-string check for `newUserId`, add a UUID format check:
   ```ts
   if (!UUID_REGEX.test(newUserId.trim())) {
     setFormError(
       'User ID must be a valid UUID (e.g. xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx). ' +
       'Ask your team member to share their account User ID from their profile settings.'
     );
     return;
   }
   ```
   This goes BEFORE `assignMutation.mutate(...)` is called, so the 422 is never triggered.

3. Update the form label and placeholder to clarify the field format:
