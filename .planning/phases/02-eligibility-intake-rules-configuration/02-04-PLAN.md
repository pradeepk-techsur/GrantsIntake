<objective>
Close two major UAT gaps from Phase 2:

1. **OpportunitiesIndex placeholder** — `client/src/pages/grantor/OpportunitiesIndex.tsx` unconditionally renders a "No opportunities yet" alert, never fetching existing opportunities from the API. Grantors cannot navigate to any existing opportunity via the UI, making Phase 2 tabs (Eligibility Rules, Pre-Screening, Conditional Sections, Attachments, Screening Criteria) effectively unreachable.

2. **Publish route bypasses PublicationService** — `POST /api/v1/opportunities/:id/publish` runs a hand-rolled `pool.query UPDATE` that omits `public_slug`. `PublicationService.publish()` correctly generates a slug but the route never calls it, leaving `public_slug = NULL` after every publish — breaking the public opportunity detail URL.

Purpose: Unblock UAT Tests 2, 3, 4, 5, 6 (all blocked by opportunity listing) and fix UAT Test 7 (null public_slug), which in turn unblocks Tests 8, 9, 10 (public portal navigation).
Output: Updated `OpportunitiesIndex.tsx` with live API fetch + card list; updated publish route delegating to `publicationService.publish()`.
</objective>
