```sql
-- addenda (F17) — published opportunity changes
CREATE TABLE addenda (
    addendum_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    opportunity_id      UUID NOT NULL REFERENCES opportunities(opportunity_id),
    addendum_type       VARCHAR(30) NOT NULL,
    -- date_change, requirement_change, clarification, correction, other
    title               VARCHAR(250) NOT NULL,
    body                TEXT NOT NULL,
    version_number      INTEGER NOT NULL,
    is_required_change  BOOLEAN NOT NULL DEFAULT FALSE,
    published_by        UUID NOT NULL REFERENCES users(user_id),
    published_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
    superseded_at       TIMESTAMPTZ  -- immutable once published
);
CREATE INDEX idx_addenda_opportunity ON addenda(opportunity_id);
CREATE INDEX idx_addenda_published_at ON addenda(opportunity_id, published_at DESC);
```

Additionally, add a `public_slug` column and GIN full-text index to the opportunities table if not already present:

```sql
ALTER TABLE opportunities ADD COLUMN IF NOT EXISTS public_slug VARCHAR(200) UNIQUE;
CREATE INDEX IF NOT EXISTS idx_opportunities_fts ON opportunities USING GIN (
```

**Step 2 — Create src/services/opportunity/publicationService.ts**:
- `publish(opportunity_id, user_id)` →
  1. Call CompletenessService to get blockers; if any, throw 400 with blockers list
  2. Generate public_slug: slugify(opportunity.title) + '-' + opportunity_id.substring(0, 8) (e.g., "federal-nofo-climate-2026-a1b2c3d4"); ensure uniqueness with retry if slug already exists
  3. UPDATE opportunities SET status='published', public_slug=slug, published_at=now()
  4. Call VersioningService to snapshot the publish event
  5. INSERT audit_events(event_type='OPPORTUNITY_PUBLISHED', entity_type='opportunity', entity_id=opportunity_id, performed_by=user_id)
  6. Return updated opportunity record with public_slug
- `getStatusBadge(opportunity)` → returns 'open' | 'closing_soon' | 'closed' | 'not_yet_open':
  - If application_close_date < now() → 'closed'
  - If application_open_date > now() → 'not_yet_open'
  - If application_close_date - now() ≤ 7 days → 'closing_soon'
  - Else → 'open'

**Step 3 — Create src/services/opportunity/addendaService.ts**:
- `list(opportunity_id)` → SELECT * FROM addenda WHERE opportunity_id=$1 ORDER BY published_at DESC
- `create(opportunity_id, data, user_id)` →
  1. Verify opportunity is published (status='published'); if not, throw 400 "Cannot add addendum to unpublished opportunity"
  2. SELECT MAX(version_number) FROM addenda WHERE opportunity_id=$1 → new_version = max + 1 (or 1 if none)
  3. INSERT with addendum_type, title, body, version_number, is_required_change, published_by=user_id, published_at=now(), superseded_at=NULL (immutable after insert — no UPDATE allowed)
  4. Return created addendum
- `delete` → NOT IMPLEMENTED — addenda are immutable. Any DELETE call returns 405 Method Not Allowed.

**Step 4 — Create src/services/opportunity/searchService.ts**:
Implements the EXACT search params from TechArch:
```typescript
interface OpportunitySearchParams {
  keyword?: string;
  funder?: string;
  program_area?: string;
  geography?: string;
  eligibility_type?: string;
  funding_min?: number;
  funding_max?: number;
  due_date_from?: string;
  due_date_to?: string;
  application_stage?: string;
  sort_by?: 'relevance' | 'deadline' | 'amount';
  page?: number;
  page_size?: number;
}
```

Implementation:
- Base query: SELECT opportunities.* FROM opportunities WHERE status='published'
- keyword: AND to_tsvector('english', coalesce(title,'') || ' ' || coalesce(description,'') || ' ' || coalesce(program_area,'')) @@ plainto_tsquery('english', $keyword) — uses the GIN index
- funder: AND grantor_org_id = (SELECT org_id FROM grantor_organizations WHERE name ILIKE $funder LIMIT 1)
- program_area: AND program_area ILIKE '%'||$program_area||'%'
- geography: AND eligible_geographies::text ILIKE '%'||$geography||'%' (JSONB cast search)
- funding_min/max: AND max_award_amount >= $min AND max_award_amount <= $max
- due_date_from/to: AND application_close_date >= $from AND application_close_date <= $to
- application_stage: AND application_stage = $stage
- sort_by='relevance': ORDER BY ts_rank(to_tsvector('english',...), plainto_tsquery($keyword)) DESC (only when keyword provided, else by published_at DESC)
- sort_by='deadline': ORDER BY application_close_date ASC NULLS LAST
- sort_by='amount': ORDER BY max_award_amount DESC NULLS LAST
- Default sort: published_at DESC
- Pagination: LIMIT page_size (default 20, max 100) OFFSET (page-1)*page_size
- Return: { opportunities: OpportunityCard[], total: number, page: number, page_size: number }
