**Phase:** 8 — Enhancements: Grants.gov Opportunity Ingestion  
**Plan:** 08-01 of 05  
**Status:** Pending  
**Requirements:** PRD-INTAKE-019A, PRD-INTAKE-019B, PRD-INTAKE-019E

## Goal

Build the backend ingestion pipeline that calls the Grants.gov Opportunity Search and Detail APIs, normalizes opportunity metadata into a canonical internal schema, persists source attribution and version history, and runs on a configurable schedule.

---

## Tasks

### Task 1: Database Migration — external_opportunities schema

**Migration:** `017_external_opportunities.sql`

Tables:
- `external_opportunities` — canonical normalized record of each Grants.gov opportunity
  - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
  - `source VARCHAR(50) NOT NULL DEFAULT 'grants.gov'` — source attribution (PRD-INTAKE-019E)
  - `source_url TEXT NOT NULL` — canonical Grants.gov URL (PRD-INTAKE-019E)
  - `source_opportunity_number VARCHAR(100) UNIQUE NOT NULL` — FON (funding opportunity number)
  - `source_assistance_listing VARCHAR(50)` — CFDA/assistance listing number (PRD-INTAKE-019B)
  - `api_reference JSONB NOT NULL DEFAULT '{}'` — raw API response snapshot (PRD-INTAKE-019E)
  - `import_timestamp TIMESTAMPTZ NOT NULL DEFAULT NOW()` — first import timestamp (PRD-INTAKE-019E)
  - `last_fetched_at TIMESTAMPTZ NOT NULL DEFAULT NOW()` — last API poll timestamp
  - `title TEXT NOT NULL` — normalized from API (PRD-INTAKE-019B)
  - `agency VARCHAR(255)` — sponsoring agency (PRD-INTAKE-019B)
  - `opportunity_status VARCHAR(50)` — forecasted/posted/closed/archived (PRD-INTAKE-019B)
  - `eligibility_summary TEXT` — normalized eligibility text (PRD-INTAKE-019B)
  - `due_date DATE` — application deadline (PRD-INTAKE-019B)
  - `award_ceiling NUMERIC(15,2)` — max award amount (PRD-INTAKE-019B)
  - `award_floor NUMERIC(15,2)` — min award amount (PRD-INTAKE-019B)
  - `application_package_url TEXT` — link to package (PRD-INTAKE-019B)
  - `raw_metadata JSONB NOT NULL DEFAULT '{}'` — full normalized metadata blob
  - `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
  - `updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`

- `external_opportunity_versions` — immutable version history for change tracking (PRD-INTAKE-019E)
  - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
  - `external_opportunity_id UUID REFERENCES external_opportunities(id)`
  - `version_number INTEGER NOT NULL`
  - `changed_fields JSONB NOT NULL DEFAULT '[]'` — list of field names that changed
  - `snapshot JSONB NOT NULL` — full record snapshot at this version
  - `fetched_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
  - UNIQUE(`external_opportunity_id`, `version_number`)

- `saved_external_opportunities` — user saves/tracks an external opportunity (PRD-INTAKE-019C)
  - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
  - `user_id UUID REFERENCES users(id)`
  - `external_opportunity_id UUID REFERENCES external_opportunities(id)`
  - `saved_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
  - UNIQUE(`user_id`, `external_opportunity_id`)

- `change_alerts` — pending alerts for users when tracked opportunity changes (PRD-INTAKE-019D)
  - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
  - `user_id UUID REFERENCES users(id)`
  - `external_opportunity_id UUID REFERENCES external_opportunities(id)`
  - `alert_type VARCHAR(50) NOT NULL` — `due_date_change` | `status_change` | `package_change` | `addenda_change` | `instructions_change`
  - `previous_value TEXT`
  - `new_value TEXT`
  - `is_read BOOLEAN NOT NULL DEFAULT FALSE`
  - `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`

Indexes: `source_opportunity_number`, `opportunity_status`, `due_date`, `last_fetched_at`

### Task 2: GrantsGovService — API Client & Normalizer

**File:** `src/services/grantsGovService.ts`

Implement:
- `searchOpportunities(params: SearchParams): Promise<GrantsGovSearchResult[]>` — calls `https://api.grants.gov/v1/api/search2/opportunities/search` with POST body `{ rows: 25, oppStatuses: 'posted', ...params }`. Returns paginated array.
- `getOpportunityDetail(opportunityId: string): Promise<GrantsGovDetail>` — calls `https://api.grants.gov/v1/api/opportunities/${opportunityId}`.
- `normalizeOpportunity(raw: GrantsGovDetail): NormalizedOpportunity` — maps raw API fields to internal schema:
  - `opportunityTitle` → `title`
  - `agencyName` → `agency`
  - `opportunityNumber` → `source_opportunity_number`
  - `cfdaNumbers[0]` → `source_assistance_listing`
  - `opportunityStatus` → `opportunity_status`
  - `closeDate` → `due_date`
  - `awardCeiling` → `award_ceiling`
  - `awardFloor` → `award_floor`
  - `eligibilityTypes` joined with eligibility description → `eligibility_summary`
  - package URL from `packages[0].packageURL` → `application_package_url`
  - `https://www.grants.gov/search-results-detail/${opportunityId}` → `source_url`
  - Full raw response → `api_reference`

### Task 3: ExternalOpportunityService — Persistence & Versioning

**File:** `src/services/externalOpportunityService.ts`

Implement:
- `upsertOpportunity(normalized: NormalizedOpportunity): Promise<ExternalOpportunity>` — ON CONFLICT(source_opportunity_number) DO UPDATE; computes changed_fields diff vs prior version; inserts new version row only when fields changed (PRD-INTAKE-019E).
- `createChangeAlerts(opportunityId: string, changedFields: string[], userId?: string): Promise<void>` — inserts `change_alerts` rows for all users who saved the opportunity and for relevant field-type alerts (PRD-INTAKE-019D).
- `saveOpportunity(userId: string, externalOpportunityId: string): Promise<void>` — ON CONFLICT DO NOTHING (PRD-INTAKE-019C).
- `unsaveOpportunity(userId: string, externalOpportunityId: string): Promise<void>`
- `listSavedOpportunities(userId: string): Promise<ExternalOpportunity[]>`
- `listOpportunities(filters: FilterParams): Promise<PaginatedResult<ExternalOpportunity>>` — search by status, keyword, agency, due date range, award range (PRD-INTAKE-019C)
- `getVersionHistory(externalOpportunityId: string): Promise<ExternalOpportunityVersion[]>` (PRD-INTAKE-019E)
- `getUnreadAlerts(userId: string): Promise<ChangeAlert[]>` (PRD-INTAKE-019D)
- `markAlertRead(userId: string, alertId: string): Promise<void>`

### Task 4: Ingestion Scheduler

**File:** `src/services/ingestionScheduler.ts`

Implement:
- Uses `node-cron` (add to package.json) to run `refreshAll()` on a configurable schedule — default `0 */6 * * *` (every 6 hours), configurable via `GRANTS_GOV_REFRESH_CRON` env var.
- `refreshAll()` — fetches 5 pages × 25 results = 125 most-recently-posted opportunities; upserts each; creates change alerts.
- `refreshSingle(opportunityNumber: string)` — on-demand fetch for a specific opportunity.
- Graceful error handling: logs failures per opportunity, does not abort batch on single failure.
- Started in `src/index.ts` after server boot.

### Task 5: REST API Routes

**File:** `src/routes/externalOpportunitiesRouter.ts`  
**Mounted at:** `/api/v1/external-opportunities`

Endpoints:
- `GET /` — list/search with query params `?status=posted&keyword=health&agency=HHS&page=1&limit=25` (PRD-INTAKE-019C)
- `GET /:id` — get single external opportunity with latest metadata
- `GET /:id/versions` — version history (PRD-INTAKE-019E)
- `POST /:id/save` — authenticated applicant saves/tracks an opportunity (PRD-INTAKE-019C)
- `DELETE /:id/save` — remove saved opportunity
- `GET /saved` — list user's saved opportunities (PRD-INTAKE-019C)
- `GET /alerts` — list unread change alerts for user (PRD-INTAKE-019D)
- `PUT /alerts/:alertId/read` — mark alert as read
- `POST /admin/refresh` — grantor admin: trigger on-demand refresh of all opportunities (PRD-INTAKE-019A)
- `POST /admin/refresh/:opportunityNumber` — force re-fetch a specific opportunity

Auth: `GET /` and `GET /:id` are public (no auth required). All other routes require `authenticate` middleware. `POST /admin/*` requires `requireRole('grantor_admin')`.

## Acceptance Criteria

1. GET `/api/v1/external-opportunities?status=posted` returns paginated list of Grants.gov opportunities with normalized fields
2. Scheduler runs every 6 hours (configurable) and upserts new opportunities without duplicates
3. An authenticated applicant can `POST /save` and retrieve via `GET /saved`
4. When a re-fetch detects a changed `due_date`, `change_alerts` row is created for all users who saved that opportunity
5. `GET /:id/versions` returns full immutable version history with `changed_fields` diff per version
6. `source_url`, `source_opportunity_number`, `import_timestamp`, and `api_reference` are preserved on every record
7. All integration tests pass
