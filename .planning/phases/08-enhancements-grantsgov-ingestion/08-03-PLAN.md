# Plan 08-03: Import External Opportunity into Internal Workspace

---

## Goal

Allow an applicant who has found an external Grants.gov opportunity to import it into the GrantsIntake internal workspace system — creating an internal opportunity record pre-populated with the external metadata and linking it back to the source for ongoing change tracking.

---

## Tasks

### Task 1: Backend — Import Endpoint

**File:** `src/routes/externalOpportunitiesRouter.ts` (extend)

`POST /api/v1/external-opportunities/:id/import`

Auth: `authenticate` (applicant role)

Logic:
1. Fetch `external_opportunity` record by `:id`
2. Find or create a `grantor_organization` with `source: 'grants_gov_import'` (system org for imported opps)
3. Find or create a `programs` row for the agency name
4. `INSERT INTO opportunities` with fields mapped from external_opportunity:
   - `title` ← external.title
   - `opportunity_number` ← external.source_opportunity_number
   - `funding_amount_max` ← external.award_ceiling
   - `funding_amount_min` ← external.award_floor
   - `eligibility_summary` ← external.eligibility_summary
   - `application_deadline` ← external.due_date
   - `source` ← `'grants_gov_import'`
   - `external_opportunity_id` ← external.id (new FK column — add to opportunities table via migration 018)
   - `status` ← `'imported'` (new status value)
5. Emit `OPPORTUNITY_IMPORTED` audit event with `{ external_opportunity_id, source_opportunity_number }`
6. Return `{ opportunity_id, workspace_url: '/applicant/workspaces?opportunity_id=...' }`

---

### Task 2: Migration 018 — Link opportunities to external source

**File:** `src/db/migrations/018_opportunity_external_link.sql`

```sql
ALTER TABLE opportunities
  ADD COLUMN IF NOT EXISTS external_opportunity_id UUID REFERENCES external_opportunities(id),
  ADD COLUMN IF NOT EXISTS source VARCHAR(50) DEFAULT 'internal';
```

### Task 3: Frontend — "Import to Workspace" Flow

**File:** `client/src/pages/applicant/ExternalOpportunityDetailPage.tsx` (extend)

"Import to Workspace" button:
- Shows confirmation modal: "This will create an internal copy of this opportunity in GrantsIntake. You can then start an application. Proceed?"
- On confirm: calls `POST /external-opportunities/:id/import`
- On success: navigates to the newly created internal opportunity's workspace or opportunity detail page with a success toast: "Opportunity imported successfully. You can now start an application."
- On error: shows inline `gf-alert gf-alert--error`

---

### Task 4: Imported Opportunity Badge

When an internal opportunity has `source='grants_gov_import'`, show:
- In `OpportunityCard` and `OpportunityDetailPage`: a `gf-badge gf-badge--info` badge: "Imported from Grants.gov"
- In `OpportunityBuilder` header: source attribution line: "Source: Grants.gov · {source_opportunity_number} · Imported {date}"

---

## Acceptance Criteria

1. Clicking "Import to Workspace" on an external opportunity detail page creates an internal opportunity record
2. The internal opportunity is pre-populated with title, agency, FON, award range, eligibility summary, and deadline from the external source
3. The `external_opportunity_id` FK is stored on the internal opportunity record
4. An `OPPORTUNITY_IMPORTED` audit event is emitted
5. The imported opportunity shows an "Imported from Grants.gov" badge in the internal UI
6. Integration test covers the import endpoint and validates all mapped fields
