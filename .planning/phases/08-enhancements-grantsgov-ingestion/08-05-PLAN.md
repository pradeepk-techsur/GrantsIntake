## Goal

Ensure every imported external opportunity permanently preserves its source attribution, source URL, API reference snapshot, import timestamp, and a complete immutable version history — surfaced both in the API and in the UI.

---

## Tasks

### Task 1: Source Attribution API Contract

`GET /api/v1/external-opportunities/:id` response must include:

```json
{
  "id": "...",
  "source": "grants.gov",
  "source_url": "https://www.grants.gov/search-results-detail/12345",
  "source_opportunity_number": "HHS-2026-001",
  "import_timestamp": "2026-09-02T10:00:00Z",
  "api_reference": { /* full raw Grants.gov API response */ },
  "versions": []
}
```

Integration test: assert all five fields (`source`, `source_url`, `source_opportunity_number`, `import_timestamp`, `api_reference`) are present and non-null.

---

### Task 2: Version History API Contract

`GET /api/v1/external-opportunities/:id/versions` response:

```json
[
  {
    "version_number": 1,
    "fetched_at": "2026-09-02T10:00:00Z",
    "changed_fields": [],
    "snapshot": { /* full normalized record at v1 */ }
  },
  {
    "version_number": 2,
    "fetched_at": "2026-09-08T06:00:00Z",
    "changed_fields": ["due_date"],
    "snapshot": { /* full record at v2, including new due_date */ }
  }
]
```

Rules enforced by tests:
- Version 1 is always created on first import (zero changed_fields)
- Subsequent versions are created ONLY when at least one watched field changes
- `snapshot` is a complete record copy (not a diff) — enables point-in-time reconstruction
- Versions are ordered ascending by `version_number`

### Task 4: Audit Events for Ingestion Actions

Emit `audit_events` rows for:
- `EXTERNAL_OPPORTUNITY_IMPORTED` — when a record is first ingested from Grants.gov
- `EXTERNAL_OPPORTUNITY_REFRESHED` — when a re-fetch detects changes
- `EXTERNAL_OPPORTUNITY_SAVED` — when a user saves an external opportunity
- `OPPORTUNITY_IMPORTED` — when an external opportunity is imported into internal workspace (covered in 08-03)

Each event: `entity_type = 'external_opportunity'`, `entity_id = external_opportunity.id`, `actor_user_id = NULL` for scheduler-driven events.

### Task 5: Regression & Coverage Tests

**File:** `src/tests/externalOpportunityAttribution.test.ts`

- Assert `source`, `source_url`, `source_opportunity_number`, `import_timestamp`, `api_reference` are all non-null after initial ingest
- Assert `import_timestamp` never changes on subsequent upserts (it is the first-import timestamp, not last-fetch)
- Assert `last_fetched_at` IS updated on every fetch
- Assert version V1 is immutable — re-seeding same opportunity does not overwrite existing V1
- Assert `audit_events` row created with `event_type = 'EXTERNAL_OPPORTUNITY_IMPORTED'` on first ingest

## Acceptance Criteria

1. Every external opportunity record exposes `source`, `source_url`, `source_opportunity_number`, `import_timestamp`, and `api_reference` in the API response
2. `import_timestamp` is set once on first import and never modified by subsequent refreshes
3. `GET /:id/versions` returns ordered immutable version history; V1 has empty `changed_fields`; subsequent versions have accurate diffs
4. `audit_events` rows are created for ingestion, refresh, save, and import actions
5. All attribution and version history regression tests pass
