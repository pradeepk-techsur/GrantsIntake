```sql
CREATE TABLE programs (
    program_id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    grantor_org_id      UUID NOT NULL REFERENCES grantor_organizations(org_id),
    program_name        VARCHAR(250) NOT NULL,
    program_area        VARCHAR(100),
    is_federal          BOOLEAN NOT NULL DEFAULT FALSE,
    program_description TEXT,
    created_by          UUID NOT NULL REFERENCES users(user_id),
    created_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
    archived_at         TIMESTAMPTZ
);
CREATE INDEX idx_programs_grantor ON programs(grantor_org_id);

CREATE TABLE opportunity_templates (
    template_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    template_name       VARCHAR(250) NOT NULL,
    template_type       VARCHAR(50) NOT NULL,
    -- federal_nofo, state_grant, philanthropic_rfp, corporate_grant, pass_through_subaward
    grant_market        VARCHAR(50),
    default_sections    JSONB,
    default_metadata    JSONB,
    is_system_template  BOOLEAN NOT NULL DEFAULT TRUE,
    owner_org_id        UUID REFERENCES grantor_organizations(org_id),
    created_by          UUID REFERENCES users(user_id),
    created_at          TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API | Authenticated React app requests (with JWT Bearer) crossing into /programs and /opportunity-templates routes |
| API→DB | Parameterized queries from programService and templateService crossing into PostgreSQL |
| db→render | programs and templates rows fetched from DB rendered in React components |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation of Privilege | GET /api/v1/programs — unauthorized org data access (IDOR) | mitigate | `programService.list(grantorOrgId)` receives grantorOrgId from `req.user` (set by authenticate middleware) — never from request body/params; SQL WHERE clause filters to caller's org |
| T-02-02 | Elevation of Privilege | POST /api/v1/programs — program creation for another org | mitigate | `requireRole('grantor_admin','program_officer')` in `src/routes/programs.ts`; program is created with `grantor_org_id` from `req.user.grantor_org_id` (not user-supplied) |
| T-02-03 | Information Disclosure | GET /api/v1/opportunity-templates — exposure of org-private templates to other orgs | mitigate | `templateService.list()` filters to `is_system_template = true OR owner_org_id = req.user.grantor_org_id`; parameterized query in service method |
| T-02-04 | Information Disclosure | Access token stored in memory/Zustand leaked to XSS | mitigate | Access token stored in Zustand memory state (NOT localStorage/sessionStorage); httpOnly cookie for refresh token; CSP headers via helmet prevent inline script injection |
| T-02-05 | Spoofing | Unauthenticated access to grantor portal routes | mitigate | Auth guard in `client/src/App.tsx` redirects to /login when access_token absent in Zustand; server-side authenticate middleware returns 401 for missing/invalid token |
| T-02-06 | Elevation of Privilege | Program Officer bypasses Intake Admin UI restriction by navigating directly to a URL | mitigate | Backend APIs enforce role requirements independently of UI; Intake Queue endpoint (Phase 6) will require intake_administrator role; UI hiding is defense-in-depth only, not sole control |
</threat_model>
