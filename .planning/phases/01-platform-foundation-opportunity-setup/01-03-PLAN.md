Business rules in `update()`:
- `contact_email`: validate RFC 5322 format (use zod `z.string().email()`)

- `funding_amount_min`: if both min and max provided, validate min <= max; return 400 with `{error: 'FUNDING_RANGE_INVALID'}`
- `assistance_listing_number`: if `funding_source` contains 'federal' (case-insensitive), validate format `\d{2}\.\d{3}`; return 400 with `{error: 'ASSISTANCE_LISTING_FORMAT_INVALID'}`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API | Opportunity create/update request bodies (all F1 fields) crossing into opportunity route handlers |
| API→DB | Parameterized queries from opportunityService crossing into PostgreSQL (opportunity CRUD + audit_events INSERT) |
| db→render | Opportunity data and guidance prompts fetched from DB rendered in React form fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | POST /programs/:programId/opportunities — create opportunity in another org's program | mitigate | `programService.getById(programId)` verifies `grantor_org_id = req.user.grantor_org_id` before create; returns 403 if program belongs to different org |
| T-03-02 | Tampering | PATCH /opportunities/:id — modify opportunity created by another org | mitigate | `opportunityService.update()` fetches opportunity, verifies `program.grantor_org_id = req.user.grantor_org_id` via join; returns 403 if mismatch (IDOR protection) |
| T-03-03 | Repudiation | OPPORTUNITY_METADATA_UPDATED — no record of what changed | mitigate | `opportunityService.update()` computes field-level diff `{field: {old, new}}` and stores in `audit_events.payload`; immutable trigger prevents modification |
| T-03-04 | Tampering | Injection via opportunity text fields (executive_summary, eligibility_summary) stored to DB | mitigate | All field values pass through Zod schema validation in route handler before reaching service; pg parameterized queries prevent SQL injection; React renders values as text nodes (not innerHTML) preventing XSS |
| T-03-05 | Information Disclosure | GET /opportunities/:id — grantor reads another org's draft opportunity | mitigate | `opportunityService.getById()` verifies opportunity's program org matches `req.user.grantor_org_id`; public read (Phase 2) will use `OpportunityDraftGuard` to restrict draft status |
| T-03-06 | Denial of Service | TemplateLibrary loads all templates on every modal open (unbounded query) | mitigate | `templateService.list()` scoped to system templates + org templates (bounded); React Query caches result for 5 minutes (staleTime: 5 * 60 * 1000) — one DB query per session not per click |
</threat_model>
