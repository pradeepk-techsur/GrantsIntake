Create `src/db/migrations/001_auth_schema.sql` with the EXACT DDL from TechArch (copy verbatim):

```sql
CREATE TABLE users (
    user_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email           VARCHAR(320) NOT NULL UNIQUE,
    full_name       VARCHAR(250) NOT NULL,
    phone           VARCHAR(30),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    last_login_at   TIMESTAMPTZ,
    is_active       BOOLEAN NOT NULL DEFAULT TRUE
);
CREATE INDEX idx_users_email ON users(email);

CREATE TABLE grantor_organizations (
    org_id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    org_name        VARCHAR(250) NOT NULL,
    org_type        VARCHAR(50),
    -- federal_agency, state_agency, foundation, corporate, other
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE grantor_roles (
    role_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    grantor_org_id  UUID NOT NULL REFERENCES grantor_organizations(org_id),
    user_id         UUID NOT NULL REFERENCES users(user_id),
    roles           JSONB NOT NULL,
    -- array of: grantor_admin, program_officer, intake_administrator,
    --           compliance_analyst, reviewer
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    revoked_at      TIMESTAMPTZ,
    CONSTRAINT uq_grantor_user_role UNIQUE (grantor_org_id, user_id)
);
CREATE INDEX idx_grantor_roles_org ON grantor_roles(grantor_org_id);
CREATE INDEX idx_grantor_roles_user ON grantor_roles(user_id);

CREATE TABLE audit_events (
    event_id        UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    event_type      VARCHAR(100) NOT NULL,
    entity_type     VARCHAR(50) NOT NULL,
    entity_id       UUID NOT NULL,
    actor_user_id   UUID REFERENCES users(user_id),
    actor_ip        INET,
    payload         JSONB,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_audit_events_entity ON audit_events(entity_type, entity_id);
CREATE INDEX idx_audit_events_actor ON audit_events(actor_user_id);
CREATE INDEX idx_audit_events_created ON audit_events(created_at);
-- IMMUTABLE: trigger rejects UPDATE/DELETE
CREATE OR REPLACE FUNCTION prevent_audit_mutation()
RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
  RAISE EXCEPTION 'audit_events rows are immutable';
END;
$$;
CREATE TRIGGER audit_events_immutable
  BEFORE UPDATE OR DELETE ON audit_events
  FOR EACH ROW EXECUTE FUNCTION prevent_audit_mutation();
```

Create `src/services/auth/tokenService.ts`:
- `signAccessToken(userId, roles)` — HS256 JWT, 15 min TTL using jose
- `signRefreshToken(userId)` — HS256 JWT, 7 day TTL, unique jti
- `verifyAccessToken(token)` — returns TokenPayload or throws
- `storeRefreshToken(userId, jti, ttlSeconds)` — store in Redis as `refresh:{userId}:{jti}`
- `revokeRefreshToken(userId, jti)` — delete from Redis
- `isRefreshTokenValid(userId, jti)` — check Redis key exists

Create `src/services/auth/authService.ts`:
- `register(email, password, fullName)` — creates user, hashes password, returns tokens; throws if email taken
- `login(email, password, ipAddress)` — validates credentials, updates last_login_at, writes GRANTOR_LOGIN audit event to audit_events (entity_type='user', entity_id=user_id, actor_ip=ipAddress), returns {user, access_token, refresh_token}
- `refresh(refreshToken)` — validates token, checks Redis, issues new access token
- `logout(userId, jti)` — revokes refresh token in Redis
- `getMe(userId)` — returns user + grantor_memberships (from grantor_roles where revoked_at IS NULL) + org_memberships

Create `src/middleware/authenticate.ts`: extracts Bearer token from Authorization header, calls tokenService.verifyAccessToken, attaches `req.user = {user_id, email, full_name, roles}` on success. Returns 401 on missing/invalid token.

Create `src/middleware/requireRole.ts`: `requireRole(...roles: GrantorRole[])` factory — checks that req.user exists and req.user.roles includes at least one of the specified roles. Returns 403 with `{error: 'PERMISSION_DENIED'}` on failure.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API | HTTP request bodies (email, password, refresh_token) crossing into auth route handlers |
| client→Redis | Refresh token JTI from untrusted client crossing into Redis lookup |
| API→DB | Parameterized queries from auth service crossing into PostgreSQL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | POST /auth/login — credential submission | mitigate | bcrypt compare in `passwordService.compare()` with work factor ≥ 12; timing-safe comparison via bcrypt internals; never log plaintext password |
| T-01-02 | Tampering | JWT access token claims (roles array) | mitigate | Token signed with HS256 secret in `tokenService.signAccessToken()`; `tokenService.verifyAccessToken()` validates signature before any role check in `authenticate.ts` middleware |
| T-01-03 | Repudiation | GRANTOR_LOGIN event — denial of login | mitigate | `authService.login()` writes immutable `audit_events` row (entity_type='user', event_type='GRANTOR_LOGIN') with actor_ip before returning tokens; DB trigger rejects UPDATE/DELETE on audit_events |
| T-01-04 | Information Disclosure | POST /auth/register — user enumeration via error message | mitigate | `authService.register()` returns generic 409 `{error: 'EMAIL_TAKEN'}` — no "user not found" vs. "wrong password" differentiation; same response shape for both login failure cases |
| T-01-05 | Denial of Service | POST /auth/login — brute-force password attack | mitigate | express-rate-limit on auth router: 20 req/min per IP; configured in `src/routes/auth.ts` before all auth handlers |
| T-01-06 | Elevation of Privilege | Refresh token reuse after logout | mitigate | `tokenService.revokeRefreshToken()` deletes Redis key `refresh:{userId}:{jti}` on logout; `isRefreshTokenValid()` checks Redis existence before issuing new access token in `authService.refresh()` |
| T-01-07 | Elevation of Privilege | Missing role check on protected routes | mitigate | `requireRole()` middleware in `src/middleware/requireRole.ts` gates all grantor-only routes; integration test in auth.test.ts asserts 403 returned for wrong role on a guarded route |
</threat_model>
