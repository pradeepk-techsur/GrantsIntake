**Step A — Backend: add GET /opportunities/:opportunityId/my-questions to src/routes/qa.ts**

Insert a new route BEFORE the existing PUT /questions/:questionId/answer (line 111). The route:
- Requires `authenticate` middleware (no `requireRole` — any authenticated user can fetch their own questions)
- Derives `submitterUserId` from `req.user!.user_id`
- Calls `qaService.listMyQuestions(opportunityId, submitterUserId)` (add this method to qaService)
- Returns the array as JSON

Add `listMyQuestions` to `src/services/opportunity/qaService.ts`:
```typescript
/** List questions submitted by a specific user for an opportunity (applicant-facing). */
async listMyQuestions(opportunityId: string, submitterUserId: string): Promise<QAItem[]> {
  const result = await pool.query<QAItem>(
    `SELECT * FROM qa_items
     WHERE opportunity_id = $1 AND submitter_user_id = $2
     ORDER BY submitted_at DESC`,
    [opportunityId, submitterUserId],
  );
  return result.rows;
}
```

Route in qa.ts (insert between the GET /questions route and the PUT /questions/:questionId/answer route):
```typescript
// ─── NEW: GET /opportunities/:opportunityId/my-questions ─────────────────────
/**
 * Applicant fetches their own submitted questions (including pending).
 * Requires authentication. Returns all qa_items where submitter_user_id = req.user.user_id.
 */
qaRouter.get(
  '/opportunities/:opportunityId/my-questions',
  authenticate,
  async (req: Request, res: Response): Promise<void> => {
    try {
      const items = await qaService.listMyQuestions(
        req.params.opportunityId,
        req.user!.user_id,
      );
      res.json(items);
    } catch (err) {
      console.error('Q&A listMyQuestions error:', err);
      res.status(500).json({ error: 'INTERNAL_ERROR', message: 'Failed to fetch your questions' });
    }
  },
);
```

async listMyQuestions(opportunityId: string): Promise<QAItem[]> {
  const res = await fetch(`${BASE}/opportunities/${opportunityId}/my-questions`, {
    headers: authHeaders(),
  });
  if (!res.ok) {
    const body = await res.json().catch(() => ({}));
    throw Object.assign(new Error(body.message || 'Failed to fetch your questions'), {
      status: res.status,
    });
  }
  return res.json();
},
