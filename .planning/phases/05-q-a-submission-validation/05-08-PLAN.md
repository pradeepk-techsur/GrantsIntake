<objective>
Fix Q&A discoverability for grantors — UAT Test 2 failed because no UI path clearly leads from the grantor sidebar to the Q&A management page for a specific opportunity.

Purpose: Users couldn't answer submitted questions because (1) the sidebar "Q&A Inbox" link leads to /grantor/opportunities with no explanation, (2) no opportunity card has a Q&A link, and (3) the OpportunityBuilder page has no "Opportunity Builder" label so users navigating by trial-and-error don't know they've arrived.

Output: Three surgical UI changes that together create a clear, discoverable path to Q&A management:
1. Each opportunity card in OpportunitiesIndex gets a "Manage Q&A" link
2. The sidebar "Q&A Inbox" is relabeled "Q&A Management" pointing to /grantor/opportunities with a note that Q&A is managed per opportunity
3. OpportunityBuilder page header shows "Opportunity Builder" as a subtitle
</objective>

Enables: None
</feature_dependencies>

**Root cause:** Users looking for Q&A management have no direct path. The opportunity card (OpportunitiesIndex.tsx) has only a title Link and a tag/date display — no Q&A link. The sidebar "Q&A Inbox" navigates to /grantor/qa-inbox → redirect to /grantor/opportunities (the list page), giving no indication that Q&A is inside each opportunity.

**Change 1: OpportunitiesIndex.tsx — add Q&A link per card**

In the `opportunities.map()` card render, add a card footer section with a "Manage Q&A" link to `/grantor/opportunities/${opp.opportunity_id}/qa`. Place it inside a `usa-card__footer` div AFTER the existing `usa-card__body`. Use `data-testid={`qa-link-${opp.opportunity_id}`}` for testability.

Example card structure result:
```tsx
<li key={opp.opportunity_id} className="usa-card">
  <div className="usa-card__container">
    <div className="usa-card__header">
      <h2 className="usa-card__heading">
        <Link to={`/grantor/opportunities/${opp.opportunity_id}`}>{opp.title}</Link>
      </h2>
    </div>
    <div className="usa-card__body">
      <p>
        <span className="usa-tag">{opp.status}</span> <span>{opp.announcement_type}</span>
      </p>
      <p><small>Updated: {new Date(opp.updated_at).toLocaleDateString()}</small></p>
    </div>
    <div className="usa-card__footer">
      <Link
        to={`/grantor/opportunities/${opp.opportunity_id}/qa`}
        className="usa-link"
        data-testid={`qa-link-${opp.opportunity_id}`}
        aria-label={`Manage Q&A for ${opp.title}`}
      >
        Manage Q&amp;A
      </Link>
    </div>
  </div>
</li>
```
