<objective>
Extend the existing mock-based WorkspacePage Playwright test to also verify that form fields (inputs, textareas, selects) are rendered as disabled when workspace.is_locked=true. The test uses page.route() to inject a locked workspace and mocked section fields, then asserts the disabled attribute on all rendered inputs.

Purpose: The 05-10 implementation correctly threads isLocked={workspace?.is_locked ?? false} from WorkspacePage through WorkspaceSectionPanel → SectionFormPanel → FormFieldRenderer. However, no automated test asserts this wiring. The human UAT tester found fields editable — likely because the UAT workspace was not yet submitted (is_locked=false). A permanent mock-based test proves the wiring works regardless of database state, creating a regression guard for PRD-INTAKE-054.

Output: Extended workspaceSubmission.spec.ts with a non-advisory test that mocks a locked workspace with real section fields and asserts all form inputs carry the disabled attribute.
</objective>

test('form fields are disabled in locked workspace', async ({ page }) => {
  // Mock workspace with is_locked=true
  await page.route('**/api/v1/workspaces/' + MOCK_WORKSPACE_ID, async (route) => {
    if (route.request().method() === 'GET') {
      await route.fulfill({
        status: 200,
        contentType: 'application/json',
        body: JSON.stringify({
          workspace_id: MOCK_WORKSPACE_ID,
          opportunity_id: 'test-opp-id',
          org_id: 'test-org-id',
          status: 'submitted',
          is_locked: true,
          visibility: 'shared',
        }),
      });
    } else {
      await route.continue();
    }
  });

  // Mock sections — narrative only so SectionFormPanel renders (not budget/attachments)
  await page.route('**/api/v1/workspaces/*/sections', async (route) => {
    await route.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify([
        {
          section_id: 's-narrative',
          section_type: 'narrative',
          section_name: 'Narrative',
          display_order: 1,
          status: 'complete',
          is_visible: true,
        },
      ]),
    });
  });

  // Mock section fields — two fields (text + textarea) so inputs render
  await page.route('**/api/v1/workspaces/*/fields*', async (route) => {
    await route.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify([
        {
          field_id: 'f-text-1',
          field_type: 'text',
          label: 'Project Title',
          placeholder: 'Enter title',
          help_text: '',

          current_response: null,
        },
        {
          field_id: 'f-textarea-1',

          label: 'Project Narrative',
          placeholder: 'Enter narrative',
          help_text: '',
          is_required: true,
          display_order: 2,
          validation_config: {},
          current_response: null,
        },
      ]),
    });
  });

  // Mock readiness
  await page.route('**/api/v1/workspaces/*/readiness', async (route) => {
    await route.fulfill({
      status: 200,
      contentType: 'application/json',
      body: JSON.stringify({
        overall_completion_pct: 100,
        is_ready_to_submit: false,
        authorized_rep_assigned: true,
        blocking_errors: [],
        warnings: [],
        attachment_status: [],
      }),
    });
  });

  // Mock tasks and comments to return empty arrays
  await page.route('**/api/v1/workspaces/*/tasks', async (route) => {
    await route.fulfill({ status: 200, contentType: 'application/json', body: '[]' });
  });
  await page.route('**/api/v1/workspaces/*/comments', async (route) => {
    await route.fulfill({ status: 200, contentType: 'application/json', body: '[]' });

      status: 200,

    });
  });

  // Mock opportunity title
  await page.route('**/api/v1/opportunities/*', async (route) => {
    await route.fulfill({
      status: 200,

  expect(inputCount).toBeGreaterThan(0); // mocked fields must render
